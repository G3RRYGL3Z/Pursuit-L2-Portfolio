01 / 05

Hindcast

An AI-powered anti-trend research tool built for Snarkitecture, an NYC-based architecture and design firm co-founded by Alex Mustonen. Hindcast takes a design brief and returns a structured reading of what's visually oversaturated in the brand and retail space — the moves everyone is making, the overused defaults, and the open ground where contrast lives. It is the opposite of a trend forecast.

My role: built the full retrieval pipeline — manually curated a 140-image seed corpus spanning the sneaker/streetwear and contemporary fashion verticals, and integrated the Tavily API for live web retrieval to augment the corpus in real time. Claude extracts design signal attributes from each retrieved image and synthesizes saturation patterns for the client.

Python FastAPI Claude / Anthropic API Tavily API TypeScript Retrieval Pipeline Image Corpus

03 / 05

LL88 AI Audit Tool

A proprietary field audit application built for Gaia Energy Solutions, an NYC-based energy compliance startup. Used on active job sites during NYC Local Law 88 audits — collecting light fixture counts, bulb types, room measurements, and photos while calculating Lighting Power Density (LPD) in real time as the auditor moves through the building. On audit completion, all data exports directly into a pre-formatted Excel spreadsheet, eliminating 1–2 hours of manual office entry per building. Available on both mobile and desktop. Currently in active use on contracted jobs.
